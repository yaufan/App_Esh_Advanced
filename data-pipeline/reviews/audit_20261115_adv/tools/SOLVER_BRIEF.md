# 盲解查核說明（甲級）

你是獨立查核者。這是「職業安全管理甲級／職業衛生管理甲級 技術士術科」練習題庫的正確性查核。題目檔已經**去掉答案、解題步驟與條文引用**。請你像考生一樣，只依法規條文獨立作答；之後會把你的答案和題庫答案比對，找出題庫可能有錯、漏寫，或題意不清、答案不唯一的題目。

## 規則
- 唯一事實來源：`__DIR__/corpus/text/` 下的法規全文（有機溶劑中毒預防規則附表在 `corpus/attachments_N0060017.json`）。不要上網，不要憑記憶作答；每一題都要找到並讀過條文再答（可以用 grep 找）。
- **只能讀 `__DIR__/` 這個目錄**。不可以讀取 `/home/claude/app_esh_advanced/`、`/home/claude/author_tmp/`、`/home/claude/review_tmp/`、`/home/claude/fix_tmp/`、`/home/claude/recheck_tmp/`、`/home/claude/audit_adv/` 底下其他資料夾、`/tmp/` 或其他任何可能含有答案的檔案；讀了就失去查核意義。你的暫存檔也放在這個目錄裡。
- 題目沒有告訴你依據哪一條：請自己找出最直接的依據條文（法規全名＋條號）。若同一題你認為有兩處以上條文都能正確作答，全部寫出來並在 `doubt` 說明。
- 依題目字面作答，不要猜出題者想要什麼。題幹或情境讓你無法確定唯一答案時，照最符合條文的答案作答，並在 `doubt` 寫清楚原因。
- 列舉題（「請列舉 N 項」）：把條文中**所有**符合題意的項目都列出來（可多於 N 項），概括條款（「其他…事項」）另外註明是概括條款。這樣比對時才看得出題庫有沒有漏列。
- 計算題：用 Python 實際計算，依題幹要求四捨五入；`fill` 題依空格 id 分別作答。
- 條文標 `[尚未施行-禁止出題]` 的不可當作依據；`[附表尚未施行]` 的條文不可用附表數值。如果某題非靠這種條文不可，請在 `doubt` 註明。

## 輸出
寫成 JSON 陣列到 `__DIR__/answers.json`，每個小題一筆，不可遺漏：
```json
[
  {"itemId": "SAF-X-01-1", "basis": [{"law": "起重升降機具安全規則", "article": "65"}],
   "answer": ["要點 1（盡量用條文用語）", "要點 2"], "doubt": ""},
  {"itemId": "SAF-X-01-2", "basis": [...], "answer": 72000, "doubt": ""},
  {"itemId": "SAF-X-01-3", "basis": [...], "answer": {"1": 5.6, "2": 7.7}, "doubt": ""}
]
```
- 問答題 `answer` 是字串陣列（一行一個要點；有「是否」「可否」的判斷題，第一行先寫結論）。
- `calc` 題 `answer` 是一個數值；`fill` 題是 `{"空格id": 數值}`。
- `doubt` 沒有疑問就留空字串。有下列情形一定要寫：答案不唯一、有其他條文也能作答、題幹缺少必要條件、情境敘述與條文矛盾、在條文中找不到依據。
