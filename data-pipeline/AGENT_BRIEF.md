你在為「職業安全管理甲級／職業衛生管理甲級 技術士術科」練習 APP 撰寫**自編大題**。APP 的核心是「看解題思路」：每個小題拆成 ① 認題 → ② 條文 → ③ 解題 → ④ 考卷上這樣寫。這個題庫之後可能公開販售，委託人明確要求：**不能有幻覺，每一題的題目、答案與解題內容都要有法規依據。**

## 寫作要求
1. 先讀負責範圍的法規全文，挑**甲級程度**的重點：雇主應辦理事項、計畫應含內容、人員資格與設置、檢查頻率與項目、定義、門檻數值、計算公式、主管機關的程序（申請、審查、檢查）。避免冷僻細節（申請書格式編號、罰鍰金額、附件編號）。
2. 一個大題圍繞一個工作情境或主題，`context` 寫成實務案例；2～5 個小題，`points` 合計剛好 20（用整數，如 2、4、5、6、8、10）。
3. 題幹要寫清楚依據哪部法規，並寫明要求：「列舉 N 項」「說明定義」「計算……（四捨五入至小數點後第 X 位）」。條文有適用條件（事業類別、人數、設備種類、但書）時，題幹或情境要寫足，使答案唯一。
4. **列舉題**：條文列出的款數多於 N 時，modelAnswer 列出全部非概括條款的款目，並設 `"need": N`；條文款數剛好等於 N 時全部列出、不設 need。概括條款（「其他…事項」）不可列為要點。
5. **四步寫法**（細節見 SCHEMA.md）：
   - think：題目關鍵字 → 對應哪部法規（**寫全名**）第幾條。一兩句。
   - citations：每個 modelAnswer 要點都要能在所引條文找到；quote 挑能直接支撐答案的連續原文。
   - solve：條文有幾款、題目問哪部分、為什麼排除某款（例如它是概括條款或不適用本情境）；計算題每一步一行，寫出公式出處與代入數字。
   - modelAnswer：使用者該寫在考卷上的答案，一行一個要點，前面編號「1.」「2.」…，用語貼近條文原文。
6. **計算題**：只在條文有公式或可直接計算的數值時出（例如安全係數、容許暴露時間、相加效應、換氣量、比例門檻）。題幹給足數據；用 Python 實際算出答案；`tolerance` 設成最後一位的半個單位（小數 1 位 → 0.05；整數 → 0.5）。一題要算多個數值時用 `fill`。
7. **同一大題的小題會顯示在同一頁**：小題之間不可互相洩題（後面小題的題幹不可透露前面小題的答案）。大題 `title`、`topic` 不可出現答案中的數值、期限或結論。
8. 不寫條文以外的說法：不寫「常考」「口訣」「得分重點」「陷阱」「注意不要混淆」「實務上」「一般而言」「考試重點」等；solve 只寫條文怎麼對到題目。
9. 用台灣正體中文，法規名稱用全名，條號寫「第 X 條」。不要抄任何書籍、補習班、網站的題目或解答文字。
10. 不確定、條文支撐不夠明確的題目，寧可不出。
