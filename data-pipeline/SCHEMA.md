# 題庫格式（職安甲級術科・解題思路 APP）

甲級術科是**紙筆問答**：每份試卷 5 大題、每大題 20 分、2 小時、60 分及格（技能檢定中心〈術科測試應檢人參考資料〉）。
APP 以「看解題思路」為主：每個小題都拆成四步——① 認題 → ② 條文 → ③ 解題 → ④ 考卷上這樣寫——再讓使用者對照「考卷上這樣寫」逐行勾選自己寫到的，算出得分。

題庫檔是一個 JSON 陣列，每個元素是一個「大題」。

## 大題

```jsonc
{
  "id": "SAF-A-01",            // 自編：SAF（職業安全管理）／HYG（職業衛生管理）-批次字母-兩位流水號
                               // 官方：OSAF-113-1-05、OHYG-114-1-03（O＋職類-梯次-題號）
  "exam": "safety",            // "safety" 職業安全管理甲級 | "hygiene" 職業衛生管理甲級
  "source": "self",            // "self" 自編 | "official" 官方歷屆題
  "category": 3,               // 1 職業安全衛生相關法規 | 2 職業安全衛生計畫及管理 | 3 專業課程
  "topic": "起重升降機具安全規則｜吊掛用鋼索",   // 主要依據法規｜主題（給 APP 篩選；不可洩題）
  "title": "吊掛作業用具",      // 短標題（不可洩題：不可出現答案的數值、期限、結論）
  "context": "某工廠以固定式起重機……",   // 選填：大題共用情境
  "items": [ /* 小題，1～6 題，points 合計 20 */ ],

  // 官方歷屆題另外有：
  "session": "113-1", "no": 5,
  "originalText": "官方題目原文（逐字）",
  "hasFigure": false, "figureNote": "",
  "partial": true, "omittedParts": [{"part": "(三)", "reason": "依據為教科書原理，依據庫無條文"}]
}
```

## 小題

```jsonc
{
  "id": "SAF-A-01-1",
  "type": "essay",             // "essay" 問答 | "calc" 計算（單一數值）| "fill" 計算（多個數值）
  "points": 6,
  "stem": "依起重升降機具安全規則規定，……？",

  "think": "題目問「吊掛用鋼索」的「安全係數」，對應起重升降機具安全規則第 65 條。",   // ① 認題
  "citations": [                                                                  // ② 條文
    { "pcode": "N0060013", "article": "65", "quote": "雇主對於起重機具之吊掛用鋼索，其安全係數應在六以上" }
  ],
  "solve": [                                                                       // ③ 解題
    "第 65 條第 1 項規定安全係數應在六以上；第 2 項定義安全係數＝斷裂荷重值÷所受最大荷重值。",
    "斷裂荷重值 ≥ 6 × 12000 N ＝ 72000 N。"
  ],
  "modelAnswer": [                                                                 // ④ 考卷上這樣寫（一行一個得分要點）
    "1. 依起重升降機具安全規則第 65 條，吊掛用鋼索安全係數應在六以上。",
    "2. 斷裂荷重值 ≥ 6 × 12000 N ＝ 72000 N。"
  ],
  "need": 4,                   // 選填：題目要求「列舉 N 項」而 modelAnswer 列出的條文項目較多時，填 N；自評時勾滿 N 行即滿分

  // calc 另有：
  "answer": 72000, "unit": "N", "tolerance": 0.5, "decimals": 0,
  // fill 另有：stem 用 {{1}}、{{2}} 標空格；"blanks": [{"id":"1","unit":"N"}], "answer": {"1": 72000}, "tolerance": 0.5

  "lawChangeNote": "（選填，官方舊題用）現行條文與出題年度不同之處",
  "basisNote": "（選填）不是法規條文的依據說明"
}
```

### 四步各寫什麼
- **think（認題）**：一兩句。題目的關鍵字是什麼、對應哪部法規第幾條。只寫「題目問什麼 → 哪一條」，不寫應考技巧。
- **citations（條文）**：支撐答案的條文逐字摘錄（8 字以上、連續原文、空白不計）。APP 會顯示摘錄並可點開全文。每一行 modelAnswer 都要能在這些摘錄所在的條文裡找到依據。
- **solve（解題）**：條文怎麼對到題目：條文列了哪幾款、題目問的是哪一部分、要排除什麼（例如但書、概括條款）。計算題寫出公式出處、代入數字、單位、四捨五入，每一步一行。
- **modelAnswer（考卷上這樣寫）**：使用者在紙上應該寫出的答案，一行一個得分要點，前面加「1.」「2.」編號。用語貼近條文；計算題最後一行寫出答案與單位。

### 自評計分
使用者對照 modelAnswer 勾選自己寫到的行：
- 沒有 `need`：得分＝配分 × 勾選行數 ÷ 總行數。
- 有 `need`：得分＝配分 × min(勾選行數, need) ÷ need。
- calc／fill：使用者輸入數值，由程式比對 `answer` 與 `tolerance` 自動判分；modelAnswer 一樣顯示給使用者看寫法。

## 鐵則（違反就刪題）
1. 題目、答案、四步內容的每一個事實，都只能來自 `corpus/text/` 的條文，不能用記憶補。
2. 標 `[尚未施行-禁止出題]` 的條文不能引用；`[附表尚未施行]` 的條文不能考附表數值；條文只寫「依附表」而附表不在文字裡的，不能考附表內容。
3. 「其他有關…事項」「其他經中央主管機關指定…」這類概括條款，不可列為 modelAnswer 的得分要點。
4. 引號「」裡的條文用語必須和條文逐字相同（程式會檢查：think／solve／modelAnswer 裡「」內的文字，必須逐字出現在所引條文或題目本身）。
5. 不寫依據庫查不到的東西：不寫「常考」「口訣」「得分重點」「陷阱」「注意不要混淆」「實務上」「一般而言」「考試重點」這類經驗或提示式用語（程式會擋）。
6. 計算題的數字一定要用 Python 實際算過；公式必須出自所引條文。純數學原理題（不是法規）只有在 `basisNote` 寫清楚依據時才收，且要另外經審題同意。
7. 不要抄任何補習班、書籍、網站的題目或解答文字。
